# Events API Service

Веб-сервис на ASP.NET Core (.NET 10) для управления событиями (мероприятиями).

---

## 🚀 Требования

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) или новее

---

## 🛠️ Запуск проекта

### Сборка проекта

Выполните команду сборки в корневом каталоге репозитория:

```bash
dotnet build
```

### Запуск приложения

```bash
dotnet run --project csharp-course
```

По умолчанию приложение доступно по следующим адресам:
- HTTP: `http://localhost:5132`
- HTTPS: `https://localhost:7291`

### Swagger UI

После запуска приложения интерактивная документация Swagger UI доступна по адресу:
- `http://localhost:5132/swagger` (или `https://localhost:7291/swagger`)

## 📖 Документация API

Базовый путь к контроллеру событий: `/api/events`

### Модели данных

#### `EventDto` (тело запроса при создании и обновлении)
- `title` (строка, обязательно): название мероприятия (от 2 до 100 символов).
- `description` (строка, опционально): описание мероприятия (от 2 до 1000 символов).
- `startAt` (дата/время, обязательно): дата и время начала (диапазон: 2020-01-01 — 2030-12-31).
- `endAt` (дата/время, обязательно): дата и время окончания (должна быть позже даты начала).

#### `ApiResult<T>` / `ApiBaseResult` (формат ответа)
- `success` (boolean): признак успешного выполнения запроса.
- `statusCode` (integer / HttpStatusCode): HTTP-код ответа.
- `dateTime` (datetime): дата и время формирования ответа (UTC).
- `message` (string): информационное сообщение или текст ошибки.
- `data` (T, для `ApiResult<T>`): возвращаемые полезные данные.

### Эндпоинты

#### 1. Получить все события
- **Метод**: `GET`
- **Путь**: `/api/events`
- **Ответ**:
  - `200 OK`: возвращает список всех событий (`ApiResult<IEnumerable<Event>>`).

#### 2. Получить событие по ID
- **Метод**: `GET`
- **Путь**: `/api/events/{index:guid}`
- **Параметры**: `index` (GUID) — идентификатор события.
- **Ответ**:
  - `200 OK`: событие найдено (`ApiResult<Event>`).
  - `404 Not Found`: событие с указанным идентификатором не найдено.

#### 3. Создать событие
- **Метод**: `POST`
- **Путь**: `/api/events`
- **Тело запроса**: `EventDto` (JSON)
- **Ответ**:
  - `201 Created`: событие успешно создано, возвращает GUID созданного события (`ApiResult<Guid>`).
  - `400 Bad Request`: ошибка валидации входных данных.

#### 4. Обновить событие
- **Метод**: `PUT`
- **Путь**: `/api/events/{index:guid}`
- **Параметры**: `index` (GUID) — идентификатор обновляемого события.
- **Тело запроса**: `EventDto` (JSON)
- **Ответ**:
  - `204 NoContent`: событие успешно обновлено (`ApiResult`).
  - `400 Bad Request`: ошибка валидации входных данных.
  - `404 Not Found`: событие не найдено.

#### 5. Удалить событие
- **Метод**: `DELETE`
- **Путь**: `/api/events/{index:guid}`
- **Параметры**: `index` (GUID) — идентификатор удаляемого события.
- **Ответ**:
  - `200 OK`: событие успешно удалено (`ApiResult`).
  - `404 Not Found`: событие не найдено.
